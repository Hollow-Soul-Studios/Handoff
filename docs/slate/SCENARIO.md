# MainMenu v1 -> v2: safe re-import scenario

Packages (`MainMenu_v1.zip`, `MainMenu_v2.zip`) are generated by the publisher's deterministic sample script. Both share `source.fileKey = SAMPLEKEY01`
and identical asset PNGs. Node ids are unchanged between versions except for the pasted `Panel`.

The v1 package has two screens (`Main Menu`, `HUD`) and one button set (`Button`, with Default / Hover / Pressed /
Disabled variants). Imported into `Source/<YourModule>/UI/Handoff` it generates the screen classes `SMainMenu`
and `SHUD`, a button class for the set (`SButtonWidget`: `SButton` is taken by the engine widget) and the style class
`FHandoffUIStyle`, each as `Generated/<Class>Base.h/.cpp` plus your own `<Class>.h/.cpp`.

## Test script

1. Import `MainMenu_v1`. Build the project (refresh the project files first).
2. Write user code in **your own classes** (`SMainMenu.cpp`, `SHUD.cpp`) that references generated members:
   * `Play`, `Quit`, `Title`, `Version` and `Footer` in `SMainMenu.cpp` (for example
     `fig_<hash>->SetOnClicked(...)`, `SetText` on the texts, and a call that only a box has on `Footer`,
     such as `fig_<hash>->AddSlot()` on the `SHorizontalBox`);
   * `Ammo` in `SHUD.cpp`.

   The member names are `fig_<8 hex of the node id>` (see the comments in `Generated/SMainMenuBase.h`).
3. Edit **generated files by hand** (4 edits, suggested; the importer must keep them where the design did not
   touch the same lines or their neighbours):
   * `SMainMenuBase.cpp`, the `Title` text block: change the `Font` line (v2 changes the font size to 64 -> conflict);
   * `SMainMenuBase.cpp`, the `Version` text block: change the `ColorAndOpacity` line (v2 changes the colour -> conflict);
   * `SMainMenuBase.cpp`, `Menu`: change the item-spacing padding line on a child slot (v2 changes 16 -> 20 -> conflict);
   * `SMainMenuBase.cpp`, `Background`: add a `.ToolTipText(...)` line at the end of its arguments (a pure hand edit; the design does not change `Background` -> kept).
4. Import `MainMenu_v2` over it: **Plan**, review, **Apply** (pass 1, defaults). Build.
5. Because your code uses `Footer`, pass 1 leaves `SMainMenu` untouched. To bring the Main Menu changes in, change
   `Footer` to **Take Figma** in the plan (the three merge conflicts and the other Main Menu changes then appear),
   or first remove your use of `Footer`, and import again (pass 2).
