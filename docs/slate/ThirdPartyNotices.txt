Handoff for Slate - Third-party notices
=======================================

1. The Unreal Engine plugin bundles no third-party code
-------------------------------------------------------
The modules under Source/ (SlateHandoffCore, SlateHandoffEditor) were written for this project and contain no
third-party source code, libraries or binary assets. The plugin depends only on Unreal Engine modules. The code it
generates for your project depends only on the engine modules Slate and SlateCore. Unreal Engine is subject to its
own license (Epic Games EULA).

The line-level three-way merge (diff3) used for re-imports is an original implementation of the textbook
algorithm; no merge library or tool code is included.

The sample packages in Samples/ (MainMenu_v1/, MainMenu_v2/) are generated by the publisher's internal
sample script and contain only synthetic, procedurally drawn images.

2. Inspirations (no code used)
------------------------------
The following projects were studied for behaviour and ideas only. No source code from them was copied or adapted.
Details are in Docs/DesignLog.md.

  * Figma2UMG (https://github.com/Buvi-Games/figma2umg), MIT License - behaviour of component, variant and instance
    mapping and patch-style updates was studied.
  * UnityFigmaBridge (https://github.com/simonoliver/UnityFigmaBridge), MIT License - inspiration for components as
    prefabs, font download and re-applying user setup after a sync.

If code from any of these projects is ever adapted, its copyright and license notice will be added here.

3. Fonts
--------
No font files are bundled. The optional "Download Google Font (OFL)" action is triggered by the user, fetches only
families that are published under the SIL Open Font License (the importer checks google/fonts ofl/<family>/OFL.txt
before downloading), and saves the font together with its OFL.txt. Downloaded fonts remain under their own license
(SIL OFL 1.1 and the copyright of each font's authors); the license text is kept next to the font files and is copied
with them into the resources folder of your project (Fonts/<Family>-OFL.txt). Fonts you map yourself are subject to
your own license for them. Packaged games that use those fonts ship them as files; keep the license files with them.
